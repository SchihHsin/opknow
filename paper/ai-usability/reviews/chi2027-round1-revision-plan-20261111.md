## 4. AC 要求二：有限独立评分与可靠性核查

### 4.1 评分过程与抽样

- [ ] 查原始评分记录，逐项说明 M1–M11 由谁或什么系统赋值，哪些来自日志、哪些涉及解释性判断，哪些经过人工复核；不把事后整理称为独立评分。
- [ ] 在既有任务侧记录中预先抽取约 **10–15 条**，覆盖两生态、不同任务类型、不同分值和有代表性的边界／缺失情况；写明抽样单位、抽样框、选择规则、随机种子或有目的抽样理由。不能只挑争议最小或最能提高一致性的案例。
- [ ] 确定独立评分者和其相关经验，记录是否可能识别生态；尽可能对原评分、模型和结论盲法，无法完全盲法时如实报告。提供相同任务要求、必要原始记录和明确评分规则，保存评分时间、版本及证据。
- [ ] 评分者在看到原分和讨论结果前，独立评定 M3、M6、M9、M10，并分别记录不适用、证据不足与无法判断。若原评分来自 LLM，抽样中必须包含独立人工核验；人仅确认 LLM 建议不等于独立复评。

### 4.2 一致性与分歧处理

- [ ] 对每个指标报告独立前的逐项配对数量、完全一致比例、差一档比例及分歧表；依据适用的数据和样本量选择并解释合适的有序等级一致性统计（例如加权 kappa 或 ordinal Krippendorff's alpha），说明权重、缺失和不适用处理方式。
- [ ] 记录类别极度集中、小样本导致统计不稳定或无法计算的情况；可提供不确定区间，但不能仅用单一统计量或预先指定阈值宣称可靠性已经验证。
- [ ] 保存独立判分、证据与理由，再进行分歧讨论／裁决；分别报告裁决前结果、裁决方式和裁决后值，不把裁决后的一致性当成独立一致性。
- [ ] 抽样发现规则歧义时，先记录问题和影响范围；若需要修订规则或原分，明确版本、依据、重评范围和对结果的影响，不追溯性地抹除原记录。
- [ ] 在方法和局限中醒目说明：抽样核查不能证明全部记录的解释性评分都已完成独立验证；讨论样本规模、主观判断和模型自评偏差对结论的影响。

**完成标准：** 抽样清单、独立评分表、逐项分歧及裁决记录、可复算的一致性统计和论文中的限制说明齐全。如果没有具备独立性的人工评分者，此项保持未完成，不伪造复评结果。
